# Vivid Thought (Web-Based Communication System)

## Project Overview

This project aims to design and develop a web-based communication system called `Vivid Thought` to support university students doing group work (e.g., assignments and projects). This project will go beyond existing tools like Slack, Discord, or Teams by focusing on the unique needs of students and their group work. In this case, community-driven collaboration with Google Drive integration. 

## Viewing the Website

To view the deployed website, go to [vivid-thought.web.app](https://vivid-thought.web.app)

## Contributing

1. Install Node.js (if not already installed) from [nodejs.org](https://nodejs.org)
2. Install Firebase CLI
```bash
npm install -g firebase-tools
```
3. Navigate to the projct direcory in terminal or command prompt
4. Login to Firebase
```bash
firebase login
```
5. Make any necessary changes to the code
6. Start a live local testing server
```bash
firebase serve
```
7. Deploy changes to website
```bash
firebase deploy
```
8. Commit changes to GitHub

If you encounter any issues, please contact one of the collaborators.
